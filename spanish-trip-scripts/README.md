# 🇪🇸 Spanish Trip Survival Scripts

Practice scripts for a week-long trip to Spain, built for **two people to practise together**.
Aimed at an **A1 / A2** learner who already knows a fair bit of vocabulary.

> **Spanish variety:** These use **Castilian Spanish (Spain)** — including *vosotros*
> and the *ceceo* "th" sound (e.g. *gracias* → "GRAH-thee-ahs", *cerveza* → "ther-BEH-tha").
> If you're going to a specific city and want tweaks (e.g. Catalan phrases for Barcelona,
> Andalusian habits for Sevilla), just ask.

## How to practise (two people)

Each script has two roles:

- 🧳 **TURISTA** (Tourist) — that's you, the traveller.
- 🧑‍💼 **NATIVO/A** (Local: receptionist, waiter, passer-by…)

**Suggested drill:**
1. Person A is the Tourist, Person B is the Local. Read through once with translations.
2. Swap roles and do it again.
3. Cover the English column and try again.
4. Use the **🔁 Swap-in vocab** at the bottom of each script to change details
   (different food, room type, place names) so it doesn't get memorised word-for-word.

## Reading the pronunciation guide

Simple English-style phonetics are given in `[brackets]` under the Tourist's lines.

- Stress the syllable in **CAPS**.
- `th` = soft English "th" as in *think* (Castilian *c/z* sound).
- `rr` = rolled/trilled r. `r` = a light tap.
- `h` in the guide is silent-ish / very soft (Spanish *h* is silent; Spanish *j*/*g* is a raspy "kh").

## Universal survival phrases (learn these first!)

| English | Spanish | Say it like |
|---------|---------|-------------|
| Hello / Hi | Hola | OH-lah |
| Good morning | Buenos días | BWEH-nos DEE-as |
| Good afternoon/evening | Buenas tardes | BWEH-nas TAR-des |
| Good night | Buenas noches | BWEH-nas NOH-ches |
| Please | Por favor | por fah-BOR |
| Thank you (very much) | (Muchas) gracias | (MOO-chas) GRAH-thee-as |
| You're welcome | De nada | deh NAH-dah |
| Yes / No | Sí / No | see / noh |
| Excuse me (to get attention) | Perdone / Disculpe | per-DOH-neh / dees-KOOL-peh |
| Sorry | Lo siento | loh see-EN-toh |
| Do you speak English? | ¿Habla inglés? | AH-blah een-GLES |
| I don't understand | No entiendo | noh en-tee-EN-doh |
| Can you repeat that, please? | ¿Puede repetir, por favor? | PWEH-deh reh-peh-TEER por fah-BOR |
| More slowly, please | Más despacio, por favor | mas des-PAH-thee-oh por fah-BOR |
| I'm learning Spanish | Estoy aprendiendo español | es-TOY ah-pren-dee-EN-doh es-pan-YOL |
| How much is it? | ¿Cuánto es? / ¿Cuánto cuesta? | KWAN-toh es / KWAN-toh KWES-tah |
| Where is…? | ¿Dónde está…? | DON-deh es-TAH |
| The bill/check, please | La cuenta, por favor | lah KWEN-tah por fah-BOR |
| Goodbye | Adiós | ah-dee-OS |
| See you later | Hasta luego | AS-tah loo-EH-goh |

**Pro tip:** A friendly *"Hola, buenos días"* + *"por favor"* + *"gracias"* gets you a very
long way. Spaniards really appreciate the effort even if the rest is rocky. 😊
